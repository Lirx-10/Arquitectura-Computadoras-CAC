El siguiente programa produce la salida de un mensaje predefinido en la ventana Terminal del 
simulador WinMIPS64. Teniendo en cuenta las condiciones de control del puerto de E/S (en el 
resumen anterior), modifique el programa de modo que el mensaje a mostrar sea ingresado por 
teclado en lugar de ser un mensaje fijo.

.data
texto: .asciiz "Hola, Mundo!" ; El mensaje a mostrar
CONTROL: .word32 0x10000
DATA: .word32 0x10008

.text
lwu $s0, DATA(r0) ; $s0 = dirección de DATA
daddi $t0, $0, texto ; $t0 = dirección del mensaje a mostrar
sd $t0, 0($s0) ; DATA recibe el puntero al comienzo del mensaje

lwu $s1, CONTROL(r0) ; $s1 = dirección de CONTROL
daddi $t0, $0, 6 ; $t0 = 6 -> función 6: limpiar pantalla alfanumérica
sd $t0, 0($s1) ; CONTROL recibe 6 y limpia la pantalla

daddi $t0, $0, 4 ; $t0 = 4 -> función 4: salida de una cadena ASCII
sd $t0, 0($s1) ; CONTROL recibe 4 y produce la salida del mensaje

halt
